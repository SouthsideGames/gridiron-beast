- **Approved design:** `GRIDIRON_BEAST_GDD.md` line 324, the current GDD. Each gym club holds "that element's legendary on the roster (the only copy in the league)".
- **Legend Tracks** (same GDD, §15.8, line 374): the player tracks only a legendary that "no club owns", or a gym legendary whose badge they hold.
- **Standing of these lines:** both sit in GDD §15. The GDD's authority notice treats sections 1–23 as history that "must not override newer locked design". No newer approved source contradicts uniqueness, so it stands.
- **Task 7 specification:** at most one offensive and one defensive legendary per franchise, including AI (`docs/TASK7_FREE_AGENCY_SPECIFICATION.md` line 78).
- **Conclusion:** uniqueness is an approved rule, not only a code comment. The same Task 7 line also says "No legendary kickers or special teams"; B19 supersedes that clause.
