# Task 8 football ability presentation: the polish matrix (FX_FOOTBALL_MATRIX)

Branch `task8-fx-football` (from `task8-implementation` 5b2ae99). Owner direction 23:13 (complete polish pass for every approved
ability, form and mastery variant, following each ability's approved Beast Dex visual) and 01:03 (the artwork is meant to CHANGE to
match the Dex; gameplay identical; the renderer branch keeps the fx hook interface). Final acceptance is the owner's, in the Ability
Reviewer; the automated checks below prove presence and timing of each phase, not aesthetics (spec §13).

**Every look in this table is an intentional artwork change.** The unfinished functional visuals (legacy `ability-sigs.js`
signatures keyed by species, and the family particle shapes) are replaced, for every Dex ability event, by the looks in
`src/ui/fx/looks/*.js`. Nothing is bound to pixel identity with the earlier visuals. The legacy path stays only for legacy events
(none occur in a Task 8 game) so the descriptor interface is unchanged for the renderer branch.

Summary: **65 complete, 7 partial, 0 blocked** (72 abilities, 102 forms, 408 form x mastery variants).

## Quality levels and reduced motion

`full` draws everything; `low` halves secondary particles (`countFor`); `min` keeps at most two secondary particles but every
primary shape, the cue, the status badge / bar / battery and the field marks (the effect stays recognizable). Status marks are now
drawn at every quality (spec §13: never hide state). Reduced flash (reviewer toggle; game setting pending, I3) softens Daybreak,
Meteor Impact and Stormguard flashes. Visuals never read into the simulation (tests: the sim record is unchanged by drawing).

## Phase legend

Cells show the evidence found in the descriptors of the first-form, mastery-0 reviewer sequence (`pN` = play N of the sequence); the
tests check every variant. `n/a` = the approved Dex visual has no such phase for this ability (for example a self-only effect has no
separate target, an instant push has no persistence); the look declares it. Anticipation includes the charge / recharge bar over the
head at the snap. Persistence includes fields across plays, auras while on the field, obstacles and summons for the play, and
statuses or recharge bars carried into later plays. Cleanup is the end event, the whistle, or a field's clock running out.

## Integration items and open questions (flagged, work continued)

- **I1 Formula kicks in the match screen.** `match.js` sets `anim.fx = null` for kick animations. Second Chance, Dragon Roar and Stone Cradle draw in the reviewer (`buildKickFx(ev, lookup)` returns `{ sim, fx }` from the kick event's `res`); the match needs a one-line hook (`anim.fx = sim.kick ? buildKickFx(ev, lookup)?.fx : ...`) which is outside this branch's scope (no match.js changes).
- **I2 Pre-choice reveals on the play-call screen.** Several Dex rows say the field or mark is visible "before both teams select plays". The field reveal plays on the field's own play; the play-call screen's `fieldSvg` presnap branch is not given fields. Needs match.js to pass the pending / active fields to the presnap draw.
- **I3 Reduced flash setting.** Spec §14 asks for a reduced-flash control; only the reviewer has a local toggle. The looks honour `fxOptions.reducedFlash` once the game passes it.
- **I4 Inspect panels.** Anchor Plate's progress tick, Iron Lungs' saved-drain tick and Night Watch's inspect note belong to inspect UI that does not exist yet; the field parts are done.
- **I5 Sovereign Arm portrait indicator.** The dragon-mouth portrait marker while the defender is absent and his return animation are roster / formation UI outside the field.
- **I6 Match screen has no pre-roll.** The reviewer plays time before the snap (gates rising, Foresight's eye, Landslide's raised fists, field reveals, Prism Break). The match starts at t = 0, so `buildFx` without `meta.preroll` folds the pre-snap choreography into the first second of the play. The renderer branch can opt in by passing `{ preroll: true }` and starting at `-fx.preroll`.
- **Q4 Breakwater (WAT-05-F).** The Dex says the exact cue for the full-Strength reduction awaits alignment with the revised mechanic; the wave wall marks every sap.
- **Q5 "Ask before generating visual preview" (EAR-05-F, ICE-01-F).** Superseded by owner direction 23:13 (no intermediate approvals); implemented and left for final acceptance.
- **Q6 Cold Snap (ICE-05-F).** "Crystallizes the affected enemy ABILITY indicator, separate from the shared status badge": no per-monster ability indicator exists on the field; the crystal is drawn at the head slot. Confirm or specify the indicator.
- **Q7 Legacy status marks.** Engine status codes still draw the legacy marks (stars, ice block, squash) beside the shared badge for a few statuses (Knocked Down shows the squash and the badge). Spec §13 asks for one neutral badge; removing the legacy marks would change `ability-sigs.js statusMarks`, kept for now so legacy codes outside Task 8 statuses stay visible.
- **Q8 Charge thresholds.** `src/ui/fx/charge.js` mirrors the contracts' thresholds and cooldowns to draw bars; a contract change must update it (no gameplay effect if it drifts, only the bar).
- **Q9 Camera.** The reviewer camera is fixed per play; effects far downfield (Hoard Flight's landing at the 35, a deep Splashdown) can leave the view.
