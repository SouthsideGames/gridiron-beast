## A catalogue row

`N(id, category, rarity, trigger, metric, target, options, $t(name), $t(description))`

- **options:**
  - `cmp`: `ge` (the default), `le`, `lt` or `eq`.
  - `scope`: `franchise` or `account`.
  - `hidden`
  - `retro`: the row may be granted from history.
  - `prov`: the threshold is provisional.
  - `params`: other numbers that the description names.
  - `progress`: the metric the progress bar shows.
- **Target:** the threshold. The description shows it as `{target}`.
- **To retune a row:** change `target` (or `params`) in its row, then regenerate the catalogue docs.
- **Ids:** ids are permanent once released. To change what a row measures, add a new row instead.

## Evaluation

```
event in franchise.js ──► tracker update (once per event id) ──► checkAchievements(f, trigger, ctx)
                                                                    ├─ originals: a.when(f, ctx)  → scene (f.scenes)
                                                                    └─ catalogue: evaluateCatalogue → awardCatalogue → f.achQueue
```

- **Which rows are checked:** for each trigger, only unearned rows whose trigger matches or is `any`. Measured cost: well under 5 ms for all 200 rows (see the test).
- **Context (`x`):**
  - `g`: the game's facts (`gameFacts`).
  - `h`: a season's history entry.
  - `live`: false during backfill.
  - `H`: helpers.
  - `qualified` and `champion`.
- **Metric families:** `g_*` reads one game, `t_*` the tracker, `c_*` the campaign, `h_*` the history, `s_*` one season, `r_*` the roster, `d_*` the dex, `a_*` the account, and `p_*`, `b_*`, `aw_*` and `l_*` other franchise records.

## The tracker `f.achTrack`

Shape: `{ v, from, n:{counts}, best:{maxima}, set:{collections}, seen:[last 48 event ids], clashSeason, capYear }`.

- **`seen`:** stops a replayed game or battle from being counted twice. Ids are `g:<activity id>` and `c:<year>:w<week>:<occasion>`.
- **`set.below50` and `set.ovrMin`:** written by `trackRoster`, pruned to the current roster. They make "trained to level 50" and "reached N overall" count only growth that happened on your roster.
- **Growing data:** collections such as `set.faced` and `set.clubsBeaten` are bounded by the league: 192 families and 32 clubs.

## Persistence and sync

- **Franchise record:** `f.achievements[id] = { year, week, backfilled? }`. This is the same shape as before.
- **Account store:** entries keep `first earn`, `at`, `count` and `franchises[]`. Catalogue entries have `scene: null`. The merge rules (earliest first-earn wins, franchise lists are unioned through `links`) and cloud mirroring are unchanged. A merge cannot duplicate an entry because entries are keyed by id.
- **No removal:** nothing deletes an earned achievement. Reloading, importing or switching franchise only reads records or adds to them.
- **Unlock queue:** `f.achQueue` is kept in the save, so a reload does not lose a queued unlock. Presenting the queue removes it, so an unlock is never shown twice. It is capped at 40 entries.

## Backfill (`backfillCatalogue`, once per save via `f.achCatalogue`)

1. **Seed the tracker** from completed seasons that came before tracking began. Only lower bounds are used:
   - games, road wins and shutouts from `schedule` results;
   - a win streak, counted within each season only;
   - clubs beaten;
   - field goals, return touchdowns and defensive touchdowns from `leagueStats`;
   - each title proves one conference title and two playoff wins.
2. **Check each past season** against every `retro` row:
   - each scheduled game's result as `g`;
   - the season as `h`;
   - the season's longest field goal as `g.fgLong`.
3. **Check the current record once.**

Rows that need data the save never kept are not granted. That includes single-game box-score feats, Clash results, comebacks and a trade's timing.

## Eligibility

`achEligible(f)` is false in two cases:

- a developer shortcut has played the franchise (`f.achDev`);
- the franchise is an archive.

Test fixtures run without `localStorage` in Node, so they never reach a player's account store. The game's own weekly simulation counts as normal play.
