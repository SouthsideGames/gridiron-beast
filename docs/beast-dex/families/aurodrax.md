### Trigger / eligibility

Three consecutive completed passes each meet12/10/8/6 net yards by mastery, including YAC. Any participating offensive scrimmage play without qualifying completion, including run, sack, incomplete, INT or short completion, resets streak.

### Targets / placement

Next own released forward pass protected once per game. Would-be intercepting defender captured by spectral dragon before interception possession/stats finalize.

### Core resolution

Protected pass otherwise intercepted becomes incomplete. Dragon swallows defender. Defender misses next one scrimmage play by Aurodrax team offense, position vacant with no substitute, then returns to ordinary formation before following play. Preserve pending absence across intervening possession change.

### Recharge / frequency

One protected throw per game spent on release even no INT. Run/sack/canceled throw before release preserves charged throw but normal uncharged streak rules still apply. Partial/charged/use/capture state survives possessions, halftime and overtime until actual game end.

### Lifetime / persistence

Absence served only on next same-team offensive scrimmage play, not special teams. Defender status durations pause while absent. Return follows served play. No injury or new shared status.

### Exceptions / counterplay

Capture works regardless of defender slot and despite Dragon Call harmful-status protection. Other pass outcomes ordinary. Live defender availability ledger must be separate from roster membership. No game-end missing player.

### Visuals

Golden seal follows football. On prevented interception seal becomes dragon mouth swallowing defender, ball drops incomplete. Portrait dragon-mouth indicator while unavailable, return animation before formation.

### Progression / notes

One protected throw, not original proposed3. Streak requires consecutive qualifying completions, user1B2B. Yardage12/10/8/6 by mastery. No automatic completion.

### Ability story

Aurodrax seal treats an interception as a challenge to royal command. An ancestral dragon answers by swallowing the challenger and carrying them away for one offensive play.
