Ferrcub; common; OL; At first own block engagement each offensive play while ready, if defender begins ordinary push attempt.

### Targets / placement

### Core resolution

Ignore first 1 yard of net backward displacement that play, then ordinary strength-based pushing resumes. No extra Blocking, shed immunity, guaranteed pancake or root to permanent spot.

### Recharge / frequency

### Progression / notes
